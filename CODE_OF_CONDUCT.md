# Code of conduct

Tidings follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique ideas rather than people, and make room for newcomers.
Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests,
discussions or any other project space.

Report problems privately to the maintainers through a
[GitHub security advisory](https://github.com/apolloshadrack/tidings-webmail/security/advisories/new)
(choose "conduct" in the title) or by email to the address on the maintainer's GitHub profile. Reports
are handled confidentially.
